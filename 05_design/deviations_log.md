# RQ1 deviations log (from registration onwards)

**Template, 2026-11-03; no entries yet.** Starts on the day the RQ1 plan is registered on OSF. Every change to the registered plan, code, data or timing after that day gets one entry, written when the change is made, before any affected estimate is read. Entries are never deleted; a later entry corrects an earlier one. Report the log with the results.

## What counts as a deviation

- Any edit to the registered code after the registration commit, including bug fixes (give the commit and say which outputs it changes).
- Any harmonisation of R1 identifiers after a matching alert (PAP §5), and any hand correction to DDPM name matching (`rq1_declarations.py`).
- The timing case chosen for each province (PAP §9) and the evidence for it; R1 publication and download dates.
- Data received after registration that the PAP anticipates (DDPM lists, Treasury survey periods): log the receipt and its date. Using them as the PAP says is not a deviation, but the timing is reported.
- Anything the PAP did not anticipate.
